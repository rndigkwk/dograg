### 추천: C (일반 대화 모델 호출을 없애고, 종류별 고정 문구)

> **적용됨 (#106, 2026-10-12).** 일반 대화 세트(`tests/data/general_questions.json`) 결과:
> - 인사 0/6 → 6/6, 기능·정체 문의 0/6 → 6/6, 범위 밖 0/6 → 6/6, 감사 6/6 → 4/6
> - 가드레일 세트: 범위 밖 요청 거절 0/16 → 8/8, 주입 막음 10/16 → 7/8
> - 응답 2.0 → 0.3초
>
> 감사 holdout 2건("땡큐", "덕분에 살았어요")은 범위 밖 안내를 받는다. 두 배포에서 "너 이름이 뭐야?"에 서비스 안내가 나오는 것을 확인했다. 기록은 [wiki/safety-and-evidence.md](wiki/safety-and-evidence.md) "일반 대화를 고정 문구로".
- `none` 경로는 3% 정도로 드물다. 그 안에서 나오는 답은 대부분 서비스를 잘못 소개하거나 범위 밖 요청을 수행한 것이었다. 남겨서 얻는 것보다 잃는 것이 크다.
- 고정 문구는 4종이면 충분하다. 인사·감사·기능 문의는 짧은 규칙으로 고르고, 그 밖은 범위 안내다.
  - 인사: 서비스 소개 + 예시 질문
