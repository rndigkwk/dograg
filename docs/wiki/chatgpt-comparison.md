# ChatGPT 비교 (2026-10-29)

같은 15문항을 RagDog 앱, ChatGPT 웹, Codex에 묻고 Claude가 블라인드로 판정했다. 15문항이라 방향만 보여 준다.
스크립트는 `scripts/compare_chatgpt.py`, 질문은 `tests/data/chatgpt_compare_questions.json`이다.

## 방법

- 질문 15개는 기존 평가 세트에서 골랐다: 위급 3, 증상 4, 관리 3, 진료비 2, 장소 3.
- 기준선 두 개를 따로 비교했다.
  - **ChatGPT 웹** (`gpt-6`, 표시 이름 "GPT-6 web medium"): 실제 사용자가 쓰는 제품. 임시 채팅에서 질문마다 새 채팅으로 물었다.
  - **Codex** (`gpt-6-luna`, 추론 medium): 앱과 같은 모델이다. 그래서 "같은 모델에서 앱의 검색·DB·응급 판단이 더한 효과"를 잰다. 다만 웹 검색을 썼고 기본 지시가 코딩용이라 순수한 모델 단독은 아니다.
- 앱은 화면부터 반려견 상담이라 보호자가 "강아지"라고 쓰지 않는다. 두 기준선에는 "반려견(강아지) 보호자의 질문입니다." 한 줄을 붙여 물었다.
- 판정: Claude Haiku가 안전·정확성·구체성·쓸모·종합을 고른다. A/B 순서를 바꿔 두 번 묻고, 두 번이 같을 때만 승자로 친다(나머지는 "갈림").
- 판정은 글만 본다. ChatGPT의 지도(Mapbox, OpenStreetMap)와 앱의 지도·근거 카드 화면은 점수에 들어가지 않는다. 2차 판정부터는 앱 답 아래에 근거 카드 목록(번호와 질문)을 글로 붙였다. 처음에는 카드 없이 보내 `[사례 3]`이 "남은 자리표시자"로 읽혀 감점됐다.

## 남은 차이

- **q08 "포도를 먹여도 되나요?"**: 앱은 "이미 먹었다면 구토가 있는지 살펴보세요"라고 답했다. 포도 중독은 증상이 늦게 나타나 증상이 없어도 바로 병원에 가야 한다. 위급 질문이 아니라 응급 대처가 붙지 않았다. 독성 음식이 언급되면 "증상이 없어도 바로 연락" 안내를 붙이게 고쳤다(`TOXIN_ASKED`). 고친 답은 다시 판정하지 않았다(그날 실험 호출이 기준 200번에 가까웠다).
- **증상·관리 질문**: 기준선은 모델이 아는 일반 지식(GDV라는 병명, 하루 음수량 기준, 원인 표)을 쓴다. 앱은 규칙 1에 따라 검색된 상담에 있는 내용만 쓴다. 이 차이는 근거 기반 답변이라는 설계에서 나온다. 일반 지식을 허용할지는 정하지 않았다. 허용하면 근거 검사(`src/citations.py`)와 충실성 평가가 무엇을 막는지 다시 정해야 한다.
- ChatGPT는 "체중을 알려 주시면 더 좁혀 볼게요"처럼 되물어 쓸모 점수를 받았다. 앱은 되묻지 않는다.
