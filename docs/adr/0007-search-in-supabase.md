# ADR-0007: 벡터 검색과 키워드 검색을 Supabase(pgvector + PGroonga)로 옮김

- **상태:** 제안 (2026-10-13). 채택하면 ADR-0003(메모리 안 전수 검색)을 대체한다.

## 맥락
- 앱 메모리의 대부분은 벡터가 아니라 키워드 검색이다. Kiwi 형태소 분석기와 BM25 색인이 약 320MB를 쓴다.
- ADR-0003으로 벡터를 메모리 안 전수 검색으로 바꿔도 앱 최고 메모리는 910MB다. Streamlit Community Cloud 보장값(690MB)을 넘는다.
- 메모리가 풀리면, 메모리 때문에 접었던 실험을 다시 할 수 있다. 예: 더 큰 질문 임베딩 모델.
- 외부 DB를 써도 된다(ADR-0004 거절). Supabase 서울에는 pgvector 0.8.2와 PGroonga 3.2.5가 있다.

## 결정 (제안)
건강·보고서 컬렉션을 Supabase 서울의 표 두 개로 옮긴다(`src/supabase_store.py`, `scripts/export_supabase_store.py`).
- 벡터: pgvector HNSW. 반복 탐색을 켜서 필터 결과가 덜 차지 않게 한다.
- 키워드: PGroonga "비슷한 문서" 검색(`&@*`). Kiwi BM25를 대신한다.
- 질문 임베딩은 지금처럼 앱 안의 ONNX 모델로 한다.

**측정 (2026-10-13, 로컬에서 서울 Supabase로):**

| | Chroma + Kiwi (지금) | 메모리 안 전수 + Kiwi (ADR-0003) | **Supabase** |
| --- | ---: | ---: | ---: |
| 앱 최고 메모리 (3회) | 990~991MB | 909~910MB | **442MB** |
| chromadb / Kiwi 로딩 | 예 / 예 | 아니요 / 예 | 아니요 / 아니요 |
| 건강 useful@3, 하이브리드 (220문항) | 0.809 | 0.809 (같은 결과) | **0.818** (p=0.85, 차이 없음) |
| 보고서 정답 페이지 (상위 6, 18문항) | 16/18 | 16/18 | 15/18 |
| 하이브리드 검색 1건 (질문 임베딩 포함) p50 | 459ms | – | **242ms** |
| dense 결과가 Chroma와 같은 비율 (상위 12) | – | 0.9975 | 0.9946 (필터 0.9933) |

- **PGroonga 키워드만 쓰면 약하다.** "비슷한 문서" 방식이 useful@3 0.418, OR 검색이 0.300으로, Kiwi BM25(0.595)보다 낮다. 형태소 사전 없이 글자 n-gram으로 찾기 때문이다. 하지만 dense와 합치면 같은 수준이다. 하이브리드에서 키워드는 보조라서다.
- **검색이 더 빠르다.** Kiwi로 긴 질문을 분석하는 시간이 빠지고, DB 왕복은 서울에서 수 ms다.
- **Supabase 사용량:** 표 두 개 약 190MB(무료 한도 500MB). 상담 본문도 DB에 들어간다(소유자의 비공개 프로젝트).

## 결과 (채택하면)
- **얻는 것:**
  - 앱 최고 메모리가 절반 이하로 줄어 보장값 690MB 안에 들어간다.
  - 남는 약 250MB로 더 큰 질문 임베딩 모델 등을 시도할 수 있다.
  - 이미지와 비공개 데이터 다운로드가 작아진다.
  - 데이터를 갱신할 때 앱을 다시 배포할 필요가 없다.
- **감수하는 것:**
  - Supabase가 멈추면 두 배포의 검색이 함께 멈춘다. 장애 시 BM25만이라도 되는 대체 경로가 없다.
  - Streamlit Cloud(오리건 추정)에서는 검색마다 서울까지 왕복이 붙는다. 질문당 0.1~0.3초 예상이고 재지 않았다.
  - 무료 플랜의 미사용 일시 정지 정책을 확인하고, 필요하면 점검 작업이 DB도 깨우게 한다.
  - 보고서 정답 페이지가 1문항 줄었다(18문항이라 판단하기엔 작다).
- **채택 전에 할 것:**
  - 앱 로더를 바꾸고 회귀를 확인한다: CRAG 60, 건강 useful@3, 보고서 30/36 세트
  - Streamlit Cloud에서 실제 지연을 잰다.
  - DB 연결 실패 때의 동작(안내 문구 또는 대체 경로)을 정한다.
- **다시 검토할 조건:** Supabase 장애·지연이 운영에 문제가 되면 ADR-0003(메모리 안 전수)으로 돌아간다. 그 코드는 남겨 둔다.
