# ADR-0012: OpenAI가 응답하지 못하면 Claude Haiku 5.5가 대신 답한다

- **상태:** 채택 (2026-10-27)
- **관련:** [ADR-0011](0011-degrade-on-model-quota.md)(한도 소진 시 검색 결과로 버티기)의 "다시 검토할 조건" 첫째 항목, [slo.md](../slo.md)

## 맥락

- **장애가 되풀이됐다:** 2026-10-19 한도 소진(ADR-0011) 뒤에도 주간 SLO(2026-10-26)의 오류 4건이 모두 같은 날 OpenAI `RateLimitError`였다. 오류율 3.0%로 목표 2%를 넘었다.
- **키를 나눌 수 없다:** OpenAI 키는 학원 조직 소속이다. 평가용 프로젝트를 따로 만들 수 없어서, 평가가 운영 한도를 쓰는 일을 막을 수 없다(ADR-0011 결과).
- **낮춘 상태는 답이 아니다:** ADR-0011의 화면은 상담 사례 목록만 보여 준다. 보호자가 직접 읽어야 한다.

## 결정

1. **상담 경로의 모델 세 개에 대체 모델을 단다** (`src/resources.py`의 `with_claude_fallback`).
   - 근거 평가·위기 판정 모델, 라우터·검색어 고쳐 쓰기 등 채팅 모델, 건강 답변 모델이다.
   - LangChain `with_fallbacks`로 같은 호출을 Claude에 한 번 보낸다. 구조화 출력(`with_structured_output`)도 양쪽에 같은 스키마로 걸린다.
2. **제공자의 실패만 넘긴다.** 한도·속도 제한(429), 시간 초과, 연결 실패, 5xx이다. 우리 요청이 잘못된 400은 그대로 오류다.
3. **둘 다 실패하면 OpenAI의 오류를 올린다.** Claude의 API 오류(잘못된 키 포함)도 처리 대상에 넣어서, LangChain이 첫 오류(OpenAI)를 다시 던지게 했다. 그래서 ADR-0011의 낮춘 화면이 그대로 동작한다.
4. **모델과 설정**
   - `claude-haiku-5-5`, thinking 끔. OpenAI 근거 평가도 추론 없이 돈다. Haiku 5.5는 thinking이 켜져 있으면 `with_structured_output`의 강제 도구 호출을 받지 않는다.
   - 제한 시간과 재시도는 OpenAI 쪽과 같다(20·30·45초, 재시도 1번). 출력 상한은 4,096토큰이다.
   - 요청에 `anthropic-workspace-id` 헤더를 붙인다.
5. **키가 없으면 지금과 같다.** `ANTHROPIC_API_KEY`가 없으면 OpenAI만 쓴다. 로컬·CI 평가는 대체 경로 없이 돈다.
6. **배포와 연습**
   - Cloud Run은 Secret Manager의 `ANTHROPIC_API_KEY`, `ANTHROPIC_WORKSPACE_ID`를 받는다.
   - 배포 워크플로의 고장 연습에 `fault=openai`를 더했다. 후보 리비전의 OpenAI 주소를 아무도 듣지 않는 주소로 바꾼다. 배포 점검의 건강 질문은 낮춘 화면("degraded")이면 실패하므로, Claude가 답해야 통과한다.

## 넣지 않은 것

- **방문 준비 보고서 팀:** Responses API로 도구를 여러 번 부르는 대화다. 도중에 제공자를 바꾸면 OpenAI 추론 항목이 든 대화를 Claude가 받아야 한다. 팀은 지금처럼 실패하면 "이어서 만들기"로 둔다.
- **보고서 검색 임베딩:** OpenAI 임베딩이다. 벡터 공간이 달라서 다른 제공자로 바꿀 수 없다.

## 결과

- **얻는 것:** OpenAI 한도가 떨어지거나 멈춰도 건강 상담은 답을 쓴다. 근거 평가와 보류 판단도 그대로 돈다.
- **감수하는 것:**
  - 대체 경로의 답은 평가 세트로 재지 않았다. 병합 게이트와 주간 회귀는 OpenAI로 돈다.
  - 실패한 OpenAI 호출(재시도 1번 포함)을 기다린 뒤 넘어가서, 시간 초과일 때는 그만큼 느리다.
  - 제공자가 둘이 되어 키와 비용을 두 곳에서 본다.
- **다시 검토할 조건:**
  - 대체 경로가 자주 쓰일 때: Langfuse에서 Claude 생성 비율을 보고, 그 답을 평가 세트로 잰다.
  - 키를 나눌 수 있게 될 때(ADR-0011)
